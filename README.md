# Netflix Exploratory Data Analysis (EDA) 📊

**Exploratory Data Analysis (EDA) on Netflix dataset using Python, Pandas, Matplotlib, and Seaborn.**  
Analyzes trends in content type, genres, ratings, countries, and release years, visualizing insights to understand Netflix’s content patterns and key statistics.

---

## 🚀 Project Overview

This project performs **EDA on the Netflix dataset** to uncover:

- Distribution of Movies vs TV Shows  
- Growth of content over the years  
- Top content-producing countries  
- Popular genres on Netflix  
- Rating distributions  
- Movie duration trends  

Plots are generated using **Matplotlib** and **Seaborn**, providing clear visual insights into Netflix’s content.

---

## 🛠️ Tech Stack

- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn

📊 Key Insights

Movies dominate Netflix content compared to TV Shows.

Netflix content growth increased significantly after 2015.

USA and India are the top content-producing countries.

Drama and Comedy are the most popular genres.

Most content is rated TV-MA and TV-14.

Most Netflix movies are between 80 and 120 minutes long
